# Architecture Decisions

Append records only for significant choices with durable tradeoffs. Do not populate this file with hypothetical decisions.

## Record format

### YYYY-MM-DD — Short decision title

- **Status:** Accepted / Superseded
- **Context:** What problem and constraints required a decision?
- **Decision:** What was chosen?
- **Alternatives considered:** What was rejected and why?
- **Consequences:** Benefits, costs and follow-up implications.
- **Relevant files:** Paths to implementation or config.
